# SingleShelf

Privacy-first, ad-free gaming website that brings together:

- Completion time tracking
- Backlog and beaten games
- User ratings (1–5 stars) and reviews
- Physical and digital price tracking with sale alerts
- Wishlist
- Forums (paid)
- Daily minigames (paid)

**Aesthetic:** Frutiger Aero × Y2K — colorful, translucent, mid-90s to mid-2000s tech nostalgia.

**Status:** Phase 0 — accounts and domain set up. Building the foundation.
