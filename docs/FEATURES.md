# SingleShelf Features

## Core
- Track all video games (PC, console, handheld)
- Completion time tracking (users enter how long it took)
- Beaten games and backlog
- Wishlist
- User ratings: 1–5 stars
- Written reviews
- Price tracking (physical + digital) with sale alerts

## Ratings & Reviews Rules
- Free users can submit ratings and reviews (and see their own).
- Only paid users’ ratings appear on the main game page and count toward the public aggregate.
- Aggregate shown as “4.2 from 37 paid members”.
- Full written reviews are publicly visible only if the author is paid.
- Free users see a truncated/blurred preview + upgrade prompt.

## Forums
- Paid subscription only.

## Play
- Daily minigames with social elements (paid tiers only).
